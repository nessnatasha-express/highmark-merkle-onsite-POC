Tagging Assets in the DAM

Tags make assets findable and reusable across teams. Apply tags at upload, not after the fact, so search and reporting stay accurate.

When to tag

  • At the moment an asset is uploaded to the DAM, before it is linked to any campaign.
  • Whenever an asset is repurposed for a new persona, market, or product line.
  • When a disclosure, legal review status, or expiration date changes on an existing asset.

How to tag

  • Use controlled-vocabulary tags from the categories below, never free-text variants of the same term.
  • Apply at least one tag from each required category: Product, Persona, Asset Type, and Compliance Status.
  • Add optional tags (Market, Campaign, Channel) whenever the asset is tied to a specific initiative.
